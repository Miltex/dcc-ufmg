## Criação de testes de unidade automatizados
Criar testes unitários com o junit e mockito para todos os módulos do projeto 
consultor-pai. Adicionar a fase de testes ao realizar o comando do 
maven: mvn test e/ou mvn install. As classes de testes devem seguir a convenção: Ex.:
NomeDaClasseTest no sufixo da classe adicionar Test. Configurar o plugin do maven
surefire em todos os módulos do projeto. Os testes unitários devem estar dentro
do diretorio src/test.
